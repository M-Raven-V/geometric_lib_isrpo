# Геометрические вычисления

В данном репозитории содержатся инструменты для геометрических вычислений.

## Общее описание решения

Проект позволяет вычислять площадь и периметр нескольких плоских геометрических объектов: окружности и квадрата.

Проект написан на языке программирования Python. Для вычислений используется встроенный модуль `math`. Сторонние зависимости отсутствуют.

## Функции

### Площадь окружности

Функция `area(r)` вычисляет площадь окружности по заданному радиусу:

```python
def area(r):
    return math.pi * r * r
```

**Особенности:**
- Принимает целые (`int`) и вещественные (`float`) числа.
- Использует математическую константу π из модуля `math`.

**Примеры вызова:**

```python
print(area(5))    # 78.53981633974483
print(area(5.1))  # 81.7128249198705
```

### Длина окружности

Функция `perimeter(r)` вычисляет длину окружности по заданному радиусу:

```python
def perimeter(r):
    return 2 * math.pi * r
```

**Особенности:**
- Принимает целые (`int`) и вещественные (`float`) числа.
- Использует математическую константу π из модуля `math`.

**Примеры вызова:**

```python
print(perimeter(5))    # 31.41592653589793
print(perimeter(5.1))  # 32.044245066615886
```

### Площадь квадрата

Функция `area(a)` вычисляет площадь квадрата по заданной длине стороны:

```python
def area(a):
    return a * a
```

**Особенности:**
- Принимает целые (`int`) и вещественные (`float`) числа.

**Примеры вызова:**

```python
print(area(5))    # 25
print(area(5.1))  # 26.009999999999998
```

### Периметр квадрата

Функция `perimeter(a)` вычисляет периметр квадрата по заданной длине стороны:

```python
def perimeter(a):
    return 4 * a
```

**Особенности:**
- Принимает целые (`int`) и вещественные (`float`) числа.

**Примеры вызова:**

```python
print(perimeter(5))    # 20
print(perimeter(5.1))  # 20.4
```

## Тестирование

Для проверки корректности работы функций реализованы модульные тесты (Unit-тесты) с использованием стандартного модуля Python `unittest`.

Тесты расположены в отдельных файлах:
- `test_circle.py` — тестирование функций вычисления площади и длины окружности.
- `test_square.py` — тестирование функций вычисления площади и периметра квадрата.

### Проверяемые сценарии

Для каждой функции предусмотрены три тестовых сценария:

1. **Нулевое значение** — проверка результата при радиусе или стороне, равных нулю.
2. **Целое значение (`int`)** — проверка вычислений с целочисленным аргументом.
3. **Вещественное значение (`float`)** — проверка вычислений с вещественным аргументом.

Всего реализовано 12 тестов:
- 6 тестов для функций окружности;
- 6 тестов для функций квадрата.

Для проверки результатов используются методы:
- `assertEqual()` — для сравнения точных значений;
- `assertAlmostEqual()` — для сравнения вещественных чисел с учётом погрешности вычислений с плавающей точкой.

### Запуск тестов

Для запуска всех тестов из корневой папки проекта необходимо выполнить команду:

```bash
py -m unittest discover -s . -p "test_*.py" -v
```
